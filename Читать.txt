=============================================================
ПРОГРАММА «Delfin Маркировка»
Извлечение кодов маркировки «Честный знак» из PDF
=============================================================

ЧТО ДЕЛАЕТ ПРОГРАММА
-------------------------------------------------------------
Программа читает PDF-файлы, в которых напечатаны коды маркировки
«Честный знак» (Data Matrix), и собирает эти коды в список.

Куда это нужно:
- для перемаркировки товаров;
- для загрузки кодов на OZON;
- для передачи кодов в другие системы (1С и т.д.).


КАК ЗАПУСТИТЬ
-------------------------------------------------------------
1. Распакуйте архив в любую папку (например, на рабочий стол).
2. Дважды кликните на файле delfin PDF_DM_CSV.exe.
3. Программа откроется — ничего устанавливать не нужно.

Если Windows спросит разрешение — нажмите «Подробнее»
→ «Выполнить в любом случае». Это обычный самораспакованный
файл, собранный из открытого исходного кода.


КАК ПОЛЬЗОВАТЬСЯ (ПРОСТОЙ ПУТЬ ДЛЯ OZON)
-------------------------------------------------------------
1. Перетащите PDF-файл (или несколько) прямо в окно программы,
   либо нажмите «Выбрать PDF» / «Выбрать папку».
2. В разделе «Разделитель GS в CSV» выберите:
   - «Для OZON (GS заменён на \u001d)» — если коды пойдут на OZON;
   - «Символ GS (обычный)» — если будете копировать коды
     с настоящим невидимым разделителем.
3. Нажмите «Начать конвертацию».
4. Рядом с вашим PDF появится файл CSV с распознанными кодами.
5. Нажмите «Выгрузить Excel» — получите файл .xlsx, где внизу
   10 вкладок с разными вариантами представления кодов.


КНОПКИ В ОКНЕ
-------------------------------------------------------------
• «Выбрать PDF» — выбрать один или несколько PDF-файлов.
• «Выбрать папку» — обработать все PDF в папке (включая подпапки).
• «Объединять в один CSV файл» — собрать коды всех PDF в один файл.
• «Тёмная тема» — переключить тёмное/светлое оформление.
• «Разделитель GS в CSV» — как записывать невидимый разделитель:
      - Символ GS (обычный)            — настоящий символ (для копирования);
      - Для 1С (GS заменён на \x1d)      — текст, если нужен такой формат;
      - Для OZON (GS заменён на \u001d) — текст для Excel на OZON.
• «Начать конвертацию» — запустить обработку.
• «Остановить» — прервать обработку.
• «Перейти в папку» — открыть папку, куда сохранились CSV.
• «Открыть код» — показать коды прямо в окне: зелёная точка — код
      верный, красная — ошибка GTIN; кнопки «Копировать»/«Скопировать
      все», счётчик «×N» по каждому артикулу.
• «Выгрузить Excel» — сохранить коды в .xlsx со всеми вариантами.


ЧТО ЗНАЧИТ «РАЗДЕЛИТЕЛЬ GS»
-------------------------------------------------------------
Внутри каждого кода есть невидимый разделитель (технический символ
ASCII 29), который отделяет части кода. На OZON он обязателен.

Особенность: в файле Excel этот невидимый символ показать нельзя,
поэтому он записан текстом:
  • \x1d — для формата 1С;
  • \u001d — для формата OZON.
Настоящий невидимый разделитель доступен только в CSV-файле или при
копировании из окна «Открыть код».


ВЫГРУЗКА В EXCEL (10 ВКЛАДОК)
-------------------------------------------------------------
1. Полный код          — код целиком.
2. GTIN+Серия+Хвост    — части кода по колонкам.
3. Код идентификации   — только GTIN+серия (без криптохвоста).
4. GTIN + Кол-во       — сколько единиц на каждый артикул.
5. Части по колонкам   — полная разбивка кода.
6. Код + Статус GTIN   — верный код или ошибка.
7. Код + Дубль         — повторные коды.
8. Для 1С              — с разделителем \x1d.
9. Для OZON            — с разделителем \u001d.
10. Номер + Код        — пронумерованные коды.


СОВЕТ ДЛЯ РАБОТЫ НА OZON
-------------------------------------------------------------
Чтобы передать коды на OZON, обычно удобнее всего:
1. Конвертировать PDF;
2. Открыть вкладку «Открыть код»;
3. Нажать «Скопировать все» — коды скопируются с настоящим
   невидимым разделителем, и их можно вставить в OZON.

Если вам нужен именно файл — используйте CSV (там настоящий
разделитель) или Excel (там разделитель текстом).
