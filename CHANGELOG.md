# Журнал изменений (CHANGELOG)

Формат версий: `Major.Minor.Patch`. Номер версии хранится в `version.py`
(константа `APP_VERSION`), показывается в заголовке окна и в меню «О программе».
После каждой правки номер увеличивается.

---

## [1.8.19] — 2026-11-12

### Исправлено
- Обновление работает даже если `updater_helper.exe` не лежит рядом с программой:
  помощник теперь извлекается из встроенного в EXE ресурса во временную папку.
  Это снимает ошибку «Не найден updater_helper.exe рядом с программой».

## [1.8.18] — 2026-11-12

### Добавлено
- **Цветные кнопки по значимости**: зелёная (главное действие), синяя
  (инструменты/проверка), оранжевая (печать/экспорт), красная (стоп/отмена),
  серая (нейтральная) — в обеих темах (светлой и тёмной).
- **Модальное окно прогресса генерации** для PDF и экспорта PNG: прогресс-бар
  и кнопка «Отмена». Отмена прерывает генерацию и закрывает окно.

## [1.8.7] — 2026-11-06

### Добавлено
- В меню **«Вид»** добавлены галочки показа/скрытия вкладок: отмечена галочка —
  вкладка отображается, снята — скрыта. Нельзя скрыть последнюю видимую вкладку.

## [1.8.6] — 2026-11-06

### Добавлено
- Ранняя проверка обновлений **до построения графического интерфейса**: даже
  если главное окно программы сломано или падает при запуске, обновление всё
  равно предлагается в отдельном независящем диалоге — версия больше не может
  «устареть» так, чтобы обновление было недоступно.

## [1.8.5] — 2026-11-06

### Добавлено
- Глобальный перехват необработанных ошибок программы: подробности записываются
  в журнал-файл, а пользователю показывается окно с кнопкой
  **«Скопировать ошибку»**, чтобы её можно было отправить разработчику.

## [1.8.4] — 2026-11-06

### Исправлено
- Устранён сбой запуска `TclError: unknown color name ""` на верхней панели
  с логотипом: цвет фона шапки теперь берётся из темы, а не задаётся пустой
  строкой.

## [1.8.3] — 2026-11-06

### Исправлено
- Проверка обновлений теперь честно сообщает, если не удалось получить данные
  с GitHub (отсутствует сеть) — вместо ложного «у вас последняя версия».
  Это позволяет корректно подтянуть актуальную версию.

## [1.8.2] — 2026-11-06

### Добавлено
- Возвращена верхняя панель с **логотипом** и названием «DMTools» (иконка
  сохраняется и в тёмной теме).

## [1.8.1] — 2026-11-06

### Добавлено
- Вкладки можно **перетаскивать мышкой** для изменения их порядка.
- В меню **«Вид»** добавлены пункты активации каждой вкладки (PDF → CSV,
  CSV → DataMatrix, Предпросмотр, Быстрый DataMatrix).

## [1.8.0] — 2026-11-06

### Изменено
- Программа переименована из «Delfin Маркировка» в **DMTools** (временное имя,
  позже запланировано голосование за финальное название). Переименованы EXE
  (`DMTools.exe`), папка установки и установщик `dmtools_setup.exe`.

### Исправлено
- Вкладка «Быстрый DataMatrix»: поле ввода кода теперь многострочное — длинный
  код «Честного знака» больше не обрезается при вставке.

## [1.7.0] — 2026-11-06

### Добавлено
- Новая вкладка **«Быстрый DataMatrix»**: вручную вставляется один код маркировки,
  программа проверяет его структуру (GTIN, серия, криптоключ 91) и показывает
  DataMatrix 25×25 мм в 100 % масштабе — читается при наведении телефона
  в «Честном знаке».

## [1.6.3] — 2026-11-06

### Исправлено
- Ошибка самообновления `TypeError: wait_for_app_exit() missing 1 required positional
  argument: 'pid_hint'`. Убран неиспользуемый параметр `pid_hint`, из-за которого
  вспомогательный процесс обновления падал и не мог заменить EXE.

## [1.6.2] — 2026-11-06

### Добавлено
- В меню «Файл» добавлены пункты: «Открыть PDF с этикетками» и
  «Открыть папку с результатами».

## [1.6.1] — 2026-11-06

### Изменено
- Убраны дубликаты из лицевой панели: лейбл «Delfin Маркировка» и чекбокс
  «Тёмная тема» под шапкой больше не выводятся (они уже есть в меню).

## [1.6.0] — 2026-11-06

### Добавлено
- В меню добавлен раздел **Инструменты**: подменю «PDF → CSV»
  (Начать/Остановить, открыть папку, выгрузить Excel) и «CSV → этикетки»
  (сгенерировать PDF, печать, экспорт PNG, открыть папку).

## [1.5.1] — 2026-11-05

### Исправлено
- Ошибка при запуске (`AttributeError: no attribute 'dark_var'`): меню строилось до
  создания переменной темы. Порядок исправлен, приложение снова запускается.

## [1.5.0] — 2026-11-05

### Изменено
- Приложение переименовано в **«Delfin Маркировка»** (заголовок окна,
  «О программе», установщик, README).

### Добавлено
- Меню **Вид** с переключателем «Тёмная тема».

## [1.4.1] — 2026-11-05

### Добавлено
- Полноценное верхнее меню: **Файл** (Выход) и **Справка** (Проверить обновления, О программе).

## [1.4.0] — 2026-11-05

### Добавлено
- Самообновление: программа проверяет наличие новой версии на GitHub
  (манифест `update.json`) при запуске и по пункту меню «Справка → Проверить обновления».
- Если есть новая версия — предлагает скачать и установить её без ручной
  переустановки (вспомогательный процесс подменяет EXE и перезапускает приложение).

## [1.3.0] — 2026-11-05

### Изменено
- Укороченный код теперь включает блок `91` как есть: `01+GTIN+21+серия [GS] 91+ключ`
  (раньше короткий код содержал только `01+GTIN+21+серия`). Блок `92` по-прежнему отбрасывается.

## [1.2.1] — 2026-11-05

### Исправлено
- Deformed (прямоугольный) DataMatrix при включённом «Укороченном коде»:
  код теперь всегда квадратный (`--square` для zint) и не выходит за границы этикетки.

## [1.2.0] — 2026-11-05

### Добавлено
- Верхнее меню (шапка) программы: **Справка → О программе**.
- Окно «О программе»: название, текущая версия, краткое описание
  и список изменений по версиям (журнал изменений прямо в приложении).

## [1.1.1] — 2026-11-05

### Исправлено
- Ошибка «Не найден zint.exe» при генерации DataMatrix в автономном EXE:
  `zint.exe` теперь упаковывается внутрь собранного бинарника.

### Добавлено
- Номер версии в заголовке окна (`GS1 DataMatrix: PDF в CSV v1.1.1`).
- Номер версии в свойствах собраного EXE (FileVersion/ProductVersion).

## [1.1.0] — 2026-11-04

### Добавлено
- Дизайнер этикеток: наименование, дата производства, партия, код маркировки
  (включается/выключается, жирность, размер шрифта).
- Авто-подбор шрифта, чтобы дата/партия не выходили за ширину этикетки.
- Пунктирная рамка на каждой этикетке.
- Проверка GS1-кодов (GTIN, серийный номер, блоки 91/92, дубли) до генерации.
- Пакетная печать PDF, печать на принтер этикеток, экспорт PNG.
- Сохранение/загрузка шаблонов этикеток (профили).
- Расшифровка кода по двойному клику (GTIN/серийный/91/92).
- Журнал операций в файл, индикатор прогресса.
- Авто-подгон окна под содержимое, исправления потоков (очередь событий).

## [1.0.0] — 2026-11-02

- Первая версия: PDF → CSV (извлечение GS1 DataMatrix) и CSV → этикетки.
